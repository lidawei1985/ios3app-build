为什么能免费？

星幕/心屋跑在 LiveContainer 容器里，自己不需要签名，借容器签名运行。
容器由 SideStore 用你自己的免费 Apple ID 在手机上签（7 天一次，自动续），所以不用买 688 的开发者号，也不用连电脑。

装不上？看这里

Apple ID 登录失败：开了双重认证要去 appleid.apple.com 生成应用专用密码填进去。
SideInstaller 卡住：先把 LocalDevVPN 连上，重开 App 再试。
打开就闪退：信任那一步没做，回第 3 步。
图标提示「已过期」：打开 SideStore 刷新一下就好，别删 App（删了数据会没）。
